# Sikkerhedsgrænse for Milas Conan-univers

## Offentligt på GitHub Pages

- design og JavaScript
- faktatjekkede Conan-oplysninger
- quizspørgsmål
- lovligt anvendelige billeder med kreditering
- midlertidige quizrum via Firebase

## Må aldrig ligge i GitHub-repositoryet

- familiebilleder
- Milas dagbog eller idébog
- personlige dokumenter
- fulde navne på quizgæster
- service-account JSON
- private API-/servernøgler
- adgangskoder

## Quizdata

Gæster bruger kaldenavn og anonym Firebase-identitet. Rumkoden bør deles direkte med de inviterede. Værten sletter rummet efter brug.

## Privat sektion

Den eksisterende PIN `1234` er kun en design-demonstration. Den beskytter ikke noget og må ikke bruges som rigtig adgangskontrol.

# v0.4 – klar til rigtige Conan-billeder

Denne version er bygget, så rigtige billedfiler kan lægges direkte ind i projektet.

## Mappestruktur

```text
images/
├── hero/
│   └── conan-hero.jpg
├── gallery/
├── eras/
│   ├── sunset-season/
│   ├── kid-krow/
│   ├── superache/
│   ├── found-heaven/
│   └── wishbone/
```

## Første anbefalede filer

Læg gerne disse filer ind først:

- `images/hero/conan-hero.jpg`
- `images/gallery/kid-krow-1.jpg`
- `images/gallery/kid-krow-2.jpg`
- `images/gallery/superache-1.jpg`
- `images/gallery/found-heaven-1.jpg`
- `images/gallery/wishbone-1.jpg`
- `images/gallery/sunset-season-1.jpg`

## Vigtigt
GitHub Pages er offentlig. Brug derfor kun billeder, du har ret til at bruge, eller som du selv bevidst vælger at lægge ind.

## Sådan opdateres siden
Når billederne ligger i mapperne, skal følgende filer normalt kun opdateres:

- `app.js` – billedstier og metadata
- eventuelt `index.html` hvis du vil ændre sektioner
